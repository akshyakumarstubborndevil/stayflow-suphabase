# LunaMatch-R: Multi-Modal Lunar Image Registration System

Developed for Chandrayaan-2 Payload Alignment (OHRC, TMC-2, IIRS).

LunaMatch-R is a planetary surface image registration platform designed to align lunar imagery across illumination variations, scale differences, and multi-modal spectral bands.

## Project Structure

- `frontend/` — Frontend application built with React, TypeScript, and Vite.

## Run Locally

Open a terminal in the `frontend` directory and run:

```bash
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## Deployment

For deployment, configure the hosting platform according to the frontend build settings. The Vite production build command is:

```bash
npm run build
```

The production output directory is `dist`.
